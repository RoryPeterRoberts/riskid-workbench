# RiskID Workbench

The AI risk identification method as software: an open-source, downloadable workbench for practitioners using *AI Risk Identification: The Complete Methodology* (EON Risk Services). Every form is one of the book's templates, every rule of the method is enforced by the program, one record produces every document the method calls for, and the data stays on your machine.

Status: **design complete, build not started.** Read `docs/SPEC.md` (what it is), `docs/PLAN.md` (how it is built, round by round) and `docs/RiskID_Workbench_Brochure.pdf` (for the Risk Manager).

Apache-2.0.
